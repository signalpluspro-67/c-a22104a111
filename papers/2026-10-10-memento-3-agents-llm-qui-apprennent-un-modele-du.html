Papier de la semaine · samedi 10 octobre

Memento 3 : agents LLM qui apprennent un modèle du monde

Un agent LLM figé apprend tout seul les règles d'un environnement en tenant un cahier de règles en langage naturel qu'il réécrit chaque fois que ses prédictions se trompent.

Memento 3: Model-Based Recursive Self-Improvement through Reflective Rulebooks · arXiv 2610.11794

PASSER

Le papier résout un problème d'agent dans un jeu déterministe à état observable, où rejouer une transition donne toujours le même résultat. Les marchés sont stochastiques et non stationnaires, le filtre cell-exact replay qui fait tout tenir ne s'applique pas aux screeners actions.

Le problème qu'ils attaquent

Un LLM lâché dans un environnement inconnu doit deviner comment ce monde réagit. Avec peu d'observations, plusieurs théories du monde collent au passé mais divergent sur le futur. Les agents classiques oublient ce qu'ils apprennent entre deux épisodes ou alors il faut réentraîner le modèle. Les auteurs veulent un agent qui apprend durablement sans toucher aux poids du LLM.

Comment ça marche

📓
01

Un cahier de règles vivant

L'agent garde une mémoire externe sous forme de texte. Dedans il écrit en langage naturel ses hypothèses sur le fonctionnement du monde. Quand une zone est incertaine, il la laisse floue au lieu d'inventer. Ce cahier sert de mémoire sémantique persistante entre les épisodes.

⚙️
02

Le cahier devient du code

Le LLM lit son cahier et le compile en code Python exécutable. Ce code sert de simulateur pour prédire ce qui va se passer avant d'agir. L'agent planifie ses coups en faisant tourner ce simulateur dans sa tête. Le cahier reste la source, le code en est la traduction mécanique.

🔁
03

Boucle observer réfléchir corriger

L'agent agit, compare sa prédiction au résultat réel, et quand ça diverge il réécrit la règle fautive. Puis il recompile le code et retente. Chaque erreur de prédiction devient un signal pour patcher le cahier. C'est ça la self-improvement récursive du papier.

✅
04

Deux filtres avant d'accepter

Un nouveau code n'est validé que si deux conditions passent. D'abord le LLM juge que le code colle bien à ce que dit le cahier en texte. Ensuite on rejoue les transitions déjà vues et le code doit reproduire exactement la même chose, case par case. Sans ça, la mise à jour est rejetée.

👥
05

Plusieurs mondes en parallèle

Une variante garde une population de cahiers en concurrence. Chacun propose une théorie différente du monde et toutes partagent les observations. Quand les cahiers prédisent des choses différentes dans une zone, l'agent va justement explorer cette zone. Les désaccords entre théories guident l'exploration.

🎮
06

Testé sur jeux ARC et Pong

Ils lancent l'agent sur ARC-AGI-3, un benchmark de petits jeux de grille. L'agent résout tous les niveaux de tous les jeux publics. Sur Pong Atari, il apprend un contrôleur qui gagne 21 à 0 sans rappeler le LLM pendant la partie. Le modèle appris tourne tout seul une fois figé.

Ce qu'ils ont mesuré

  • ARC-AGI-3 : tous les niveaux des 25 jeux publics résolus par l'agent mono-modèle
  • RHAE moyen de 100.0 et 44% du nombre d'actions humaines sur ARC-AGI-3
  • Pong : 21-0 sur chacun des 3 épisodes évalués avec ouvertures différentes, zéro appel LLM pendant la partie

Ce que ça ne prouve pas

  • Testé sur des environnements jouets avec dynamique déterministe et pixels, pas sur des marchés bruités et non stationnaires
  • La vérif cell-exact replay suppose qu'on peut rejouer les transitions à l'identique, impossible sur des cours de bourse
  • Rien sur le coût en tokens de la boucle réflexion-recompilation, qui peut exploser

Chez nous

Où ça se branche

aucun fichier précis du système ne s'y branche proprement, ni les screeners (PULLBACK, BOTTOM, VSA...), ni signal_outcome.db, ni lib/llm_gateway.py

Le plan

  1. ne rien coder côté screeners
  2. si envie de creuser l'idée du cahier de règles, la réserver au harness d'agents LLM où il y a de vrais états rejouables, pas aux signaux de marché
  3. garder le papier comme référence si un jour tu veux donner une mémoire persistante aux agents Discord ou Trade Desk

Effort

0 h

Ça remplace

rien, le papier ne remplace aucune brique existante

Le risque

le risque est de perdre une semaine à forcer un branchement sur signal_outcomes, le signe serait un cahier de règles qui réécrit sans fin ses hypothèses parce que le marché bouge sous lui

Le test qui tranche

pas de test à lancer ici, le papier est hors scope. Si un jour tu testes quand même, le chiffre qui invalide est simple : un cahier qui doit être réécrit à chaque nouvelle semaine de données n'apprend rien de stable, donc inutile.

Ce que j'ai simplifié

  • j'ai présenté la compilation cahier vers code comme automatique, en vrai le LLM génère le code et peut échouer plusieurs fois avant que ça passe les deux filtres
  • j'ai glissé sur le détail de la population d'experts, le papier décrit un vrai mécanisme de partage d'observations et de vote entre cahiers
